# Better-Context v3: Fast Primitives for AI Agents

## The Core Insight

The current tool is backwards. It spends 2-10 seconds computing everything upfront, makes judgment calls about what's "important," and generates AGENTS.md with hardcoded heuristics.

**AI agents are the consumers.** They have reasoning capabilities. The tool should:
1. Provide fast data primitives (50-200ms each)
2. Return raw structured data, not interpretations
3. Let the AI agent reason about what's important
4. Let the AI agent write AGENTS.md with its own understanding

---

## New CLI Command Structure

### Fast Primitives (NEW - no manifest required)

| Command | Purpose | Target Time |
|---------|---------|-------------|
| `overview` | Project type, framework, package manager | ~100ms |
| `tree [--depth N]` | Directory structure with file counts | ~100ms |
| `scripts` | Available commands from package.json/pyproject.toml | ~50ms |
| `entries` | Entry point detection | ~50ms |
| `file <path>` | Single file metadata (exports, imports, chunks) | ~200ms |
| `deps <path>` | Dependencies and dependents of a file | ~100ms |

### Manifest-Based Commands (KEEP)

| Command | Status |
|---------|--------|
| `scan` | Keep - full analysis pipeline |
| `stats` | Keep - from manifest |
| `graph` | Keep - from manifest |
| `focus <file>` | Keep - ego-centric view |
| `optimize` | Keep - token budget optimization |
| `verify` | Keep - staleness check |
| `clean` | Keep - cleanup |

### REMOVED

| Command | Action |
|---------|--------|
| `agents` | **Delete** - AI agents should write their own AGENTS.md |
| `all` | **Delete** - was combo of deprecated scan+agents |

## Output Format

- **Default: JSON** - for programmatic use
- **`--format human`** - pretty-printed for terminals
- **`--format markdown`** - markdown tables

## AI Agent Workflow Example

```bash
# Quick context (150ms total)
overview=$(better-context overview)
tree=$(better-context tree --depth 2)
entries=$(better-context entries)

# On-demand depth for files of interest
file_info=$(better-context file src/api/routes.py)

# Agent reads actual source, forms understanding, writes AGENTS.md
```

**Benefits:**
- Get overview in 150ms instead of 5 seconds
- Only analyze files the agent cares about
- AI decides what is "important" based on the task
- Raw data, no tool interpretations
